## 5. Kesepakatan Target Performa Website

Website ini dibangun menggunakan teknologi modern (Next.js App Router, TypeScript, dan Tailwind CSS) dengan pendekatan performa tinggi agar calon pelanggan di smartphone tidak meninggalkan halaman karena loading lambat.

Berikut **usulan target SLA performa konkret** yang disepakati untuk diaudit saat peluncuran:

1. **Lighthouse Score ≥ 90 untuk Seluruh Kategori (Mobile & Desktop):**  
   - *Target:* Performance ≥ 90, Accessibility ≥ 90, Best Practices ≥ 90, SEO ≥ 90.  
   - *Alasan:* Menjamin kualitas teknis standar industri Google dan visibilitas pencarian lokal maksimal.
2. **Largest Contentful Paint (LCP) < 2.0 Detik pada Jaringan Mobile 4G:**  
   - *Target:* Banner utama dan teks pembuka muncul kurang dari 2 detik.  
   - *Alasan:* Ambang batas standar Google adalah 2.5 detik; target 2.0 detik memastikan pengunjung dari Instagram tidak mental (*bounce*).
3. **Cumulative Layout Shift (CLS) < 0.05:**  
   - *Target:* Pergeseran elemen visual saat halaman dimuat mendekati nol.  
   - *Alasan:* Gambar dan font dimuat stabil tanpa efek "lompat-lompat" saat user ingin menekan tombol menu.
4. **Interaction to Next Paint (INP) / First Input Delay < 200 ms:**  
   - *Target:* Respons instan saat tombol navigasi atau link WhatsApp ditekan.  
   - *Alasan:* Menjamin kenyamanan interaksi sentuhan di smartphone.
5. **Batas Total JavaScript (First Load JS Bundle) < 85 KB (gzipped):**  
   - *Target:* Paket skrip JavaScript awal per halaman sangat ramping.  
   - *Alasan:* Mayoritas komponen disajikan secara statis (Server Components), menghemat kuota internet dan baterai gawai pengguna.

## 6. Batasan Transparan Versi Gratis (MVP) & Jalur Upgrade Phase 2

Agar kerja sama berjalan lancar dan ekspektasi terkelola dengan baik, berikut rincian ruang lingkup **Versi Gratis** saat ini dan pemetaannya menuju **Phase 2 (Berbayar)**:

### 6.1. Apa yang Termasuk dalam Versi Gratis:
- Website berkecepatan tinggi, responsif (sempurna di HP, tablet, laptop).
- Tampilan 5 halaman utama: Home, Menu Lengkap, Tentang Cafe, Galeri Suasana, dan Lokasi & Kontak.
- Tombol aksi langsung terhubung ke WhatsApp dan petunjuk rute Google Maps.
- Optimasi SEO lokal lengkap (Google Search, Google Maps, Open Graph media sosial).

### 6.2. Batasan Teknis Versi Gratis:
1. **Menu & Harga Statis (In-Code):**  
   Data menu disimpan langsung di dalam kode program. Perubahan harga, nama menu, atau foto menu dilakukan dengan meminta bantuan developer.
2. **Reservasi Manual via Link WhatsApp:**  
   Tombol reservasi akan membuka aplikasi WhatsApp tamu dengan pesan pembuka otomatis (bukan sistem kalender pemesanan slot meja otomatis).
3. **Tanpa Dashboard Admin / Akun Login / CMS:**  
   Pemilik cafe belum memiliki halaman panel login khusus untuk mengedit isi website secara mandiri.
4. **Tanpa Database & Sistem Pembayaran:**  
   Tidak menyimpan data histori pelanggan di web dan tidak ada pembayaran otomatis di muka.

### 6.3. Alasan Alami Upgrade ke Phase 2 (Masa Depan):
Seiring bertambah ramainya pengunjung cafe dari traffic website dan Instagram, kebutuhan operasional berikut akan menjadi alasan logis untuk upgrade ke Phase 2:
- **Admin Dashboard & CMS Mandiri:** Owner / manajer cafe dapat menambah promo mingguan, mengubah stok menu habis (*sold out*), dan update harga sendiri kapan saja tanpa menunggu developer.
- **Sistem Reservasi Meja Berbasis Slot & Kalender:** Mengurangi beban kasir / admin WA saat jam sibuk (*weekend*), mencegah *double booking*, dan pencatatan DP otomatis.
- **Online Ordering & QR Table Menu:** Tamu di meja bisa memindai QR untuk memesan dan membayar langsung lewat QRIS / Payment Gateway.
- **Database Pelanggan & Analitik:** Memetakan menu terlaris dan nomor pelanggan untuk program loyalitas.
